# Web stack debugging #0

This directory contains the solution for the first web stack debugging project, focused on diagnosing why an Apache web server inside a Docker container is not responding and writing a Bash script to restore service.

## Tasks

* **0. Give me a page!** (`0-give_me_a_page`): Starts the `apache2` service inside the container so querying port `80` returns `Hello Holberton`.
